# Play Store graphics

Generated by `tools/store_assets/` (HTML recreations of the app screens, rendered with Playwright/Chromium).

| File | Play Console field | Size |
|---|---|---|
| `icon-512.png` | App icon | 512×512 |
| `<lang>/feature-graphic-1024x500.png` | Feature graphic | 1024×500 |
| `<lang>/phone/01–08.png` | Phone screenshots | 1080×1920 |
| `<lang>/tablet7/01–04.png` | 7-inch tablet screenshots | 1200×1920 |
| `<lang>/tablet10/01–04.png` | 10-inch tablet screenshots | 1600×2560 |

`<lang>` = `ar` (default listing), `fr`, `en`.

Regenerate:

```sh
python3 tools/store_assets/build_pages.py <pages_dir> <node_modules>/@fontsource
CHROME_PATH=<chromium> node tools/store_assets/capture.js <pages_dir> store/graphics
```
