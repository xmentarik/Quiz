# 💎 طريق المليون

لعبة مسابقات ثقافية لأندرويد على طريقة «من سيربح المليون»، مكتوبة بـ **Kotlin** و **Jetpack Compose**، مع أسئلة يولّدها الذكاء الاصطناعي (Google Gemini).

## الميزات الحالية

- **15 سؤالاً** متدرجة الصعوبة (5 سهلة، 5 متوسطة، 5 صعبة) وسلّم جوائز حتى **1,000,000 نقطة**.
- **نقاط أمان** عند السؤال 5 (1,000) والسؤال 10 (32,000).
- **4 وسائل مساعدة**: حذف إجابتين (50:50)، رأي الجمهور، مكالمة صديق، وتبديل السؤال (ميزة إضافية).
- **مؤقت**: 30 ثانية للأسئلة 1–5، و45 ثانية للأسئلة 6–10، وبلا حد زمني للأسئلة الأخيرة. يتوقف المؤقت أثناء عرض نتيجة وسيلة المساعدة.
- **«إجابة نهائية؟»** مع لحظة تشويق قبل كشف الإجابة.
- **شرح لكل إجابة** بعد كشفها، فاللعبة تعليمية أيضاً.
- **أسئلة لا نهائية بالذكاء الاصطناعي** في 10 مواضيع، مع رجوع تلقائي إلى أسئلة التطبيق عند انقطاع الإنترنت.
- **60 سؤالاً عربياً مدمجاً** تعمل بلا إنترنت.
- **إحصائيات**: أفضل رصيد، وعدد المباريات، ومرات الفوز بالمليون.
- **مشاركة النتيجة**، وواجهة عربية كاملة من اليمين إلى اليسار.

## التشغيل في Android Studio

1. افتح المجلد في Android Studio (نسخة Ladybug أو أحدث) واترك Gradle يحمّل المكتبات.
2. لتفعيل أسئلة الذكاء الاصطناعي، أنشئ مفتاحاً من [Google AI Studio](https://aistudio.google.com/apikey) ثم أضفه إلى ملف `local.properties` في جذر المشروع:
   ```properties
   GEMINI_API_KEY=ضع_مفتاحك_هنا
   # اختياري، القيمة الافتراضية gemini-flash-latest
   GEMINI_MODEL=gemini-flash-latest
   ```
   الملف `local.properties` مستثنى من git فلن يُرفع مفتاحك.
3. شغّل التطبيق على محاكٍ أو هاتف (Android 8.0 / API 26 فما فوق).

> إذا اقترح Android Studio ترقية Android Gradle Plugin، فاقبلها عبر *AGP Upgrade Assistant*.

الاختبارات: `./gradlew test`

## ⚠️ ملاحظة أمنية قبل النشر

المفتاح المدمج في `BuildConfig` يمكن استخراجه من ملف APK. هذا مقبول أثناء التطوير، لكن قبل النشر على Google Play انقل استدعاء Gemini إلى خادم خاص بك أو استخدم **Firebase AI Logic** مع App Check.

## بنية المشروع

```
app/src/main/java/com/xmentarik/quiz/
├── data/                       # الأسئلة ومصادرها
│   ├── Question.kt             # نموذج السؤال والتحقق من صحته
│   ├── QuestionSetBuilder.kt   # اختيار 15 سؤالاً + أسئلة احتياطية
│   ├── GeminiQuestionGenerator.kt  # توليد الأسئلة عبر Gemini (JSON منظم)
│   ├── QuestionRepository.kt   # ذكاء اصطناعي أو أسئلة محلية مع الرجوع التلقائي
│   └── StatsStore.kt           # حفظ الإحصائيات
├── game/                       # قواعد اللعبة (Kotlin خالص وقابل للاختبار)
│   ├── GameEngine.kt           # الإجابة، الانسحاب، انتهاء الوقت، وسائل المساعدة
│   ├── MoneyLadder.kt          # سلّم الجوائز ونقاط الأمان
│   └── TimeLimits.kt
└── ui/                         # Jetpack Compose
    ├── QuizViewModel.kt        # الحالة والمؤقت
    ├── home/  game/  result/   # الشاشات
    └── theme/
app/src/main/assets/questions_ar.json   # بنك الأسئلة المدمج
```
