# 💎 طريق المليون

لعبة مسابقات ثقافية لأندرويد على طريقة «من سيربح المليون»، مكتوبة بـ **Kotlin** و **Jetpack Compose**، مع أكثر من 1,000 سؤال بثلاث لغات.

## الميزات الحالية

- **15 سؤالاً** متدرجة الصعوبة (5 سهلة، 5 متوسطة، 5 صعبة) وسلّم جوائز حتى **1,000,000 نقطة**.
- **نقاط أمان** عند السؤال 5 (1,000) والسؤال 10 (32,000).
- **4 وسائل مساعدة**: حذف إجابتين (50:50)، رأي الجمهور، مكالمة صديق، وتبديل السؤال (ميزة إضافية).
- **مؤقت**: 30 ثانية للأسئلة 1–5، و45 ثانية للأسئلة 6–10، وبلا حد زمني للأسئلة الأخيرة. يتوقف المؤقت أثناء عرض نتيجة وسيلة المساعدة.
- **«إجابة نهائية؟»** مع لحظة تشويق قبل كشف الإجابة.
- **شرح لكل إجابة** بعد كشفها، فاللعبة تعليمية أيضاً.
- **اختيار الموضوع**: «كل المواضيع» أو واحد من 10 مواضيع (حوالي 100 سؤال لكل موضوع)، بلا إنترنت.
- **🚩 الإبلاغ عن خطأ**: بعد كشف الإجابة، يستطيع اللاعب الإبلاغ عن سؤال (إجابة خاطئة، غموض، خطأ في الترجمة، أخرى) مع تعليق.
- **1,093 سؤالاً مدمجاً بكل لغة** تعمل بلا إنترنت (60 كتبتها يدوياً + 1,033 ولّدها Gemini وتم التحقق منها)، مع **منع التكرار**: لا يرى اللاعب السؤال نفسه قبل حوالي 60 مباراة.
- **إحصائيات**: أفضل رصيد، وعدد المباريات، ومرات الفوز بالمليون.
- **مشاركة النتيجة**، وواجهة عربية كاملة من اليمين إلى اليسار.
- **🎵 موسيقى تشويق ومؤثرات صوتية** أصلية (انظر أدناه).
- **📳 اهتزاز** يرافق اللحظات المهمة: نبض قلب متسارع عند «إجابة نهائية؟»، ونبضتان للإجابة الصحيحة، واهتزاز طويل للخطأ، واحتفال عند الفوز.
- **🌍 ثلاث لغات: العربية والفرنسية والإنجليزية**، تختارها من الشاشة الرئيسية:
  - تنقلب الواجهة تلقائياً: من اليمين إلى اليسار للعربية، ومن اليسار إلى اليمين للفرنسية والإنجليزية.
  - الأسئلة نفسها في اللغات الثلاث (1,093 لكل لغة).
  - يبدأ التطبيق بلغة الهاتف إن كانت الفرنسية أو الإنجليزية، وإلا فبالعربية.

- **🏆 ترتيب عالمي**: أفضل 50 لاعباً وترتيبك أنت.
- **⚔️ تحدّي الأصدقاء**: أنشئ تحدياً واحصل على رمز من 6 أحرف (مثل `AB3K9Z`). يدخل أصدقاؤك الرمز ويجيبون عن **الأسئلة الخمسة عشر نفسها بالضبط**، ثم يظهر ترتيب مشترك حسب الرصيد، ثم عدد الإجابات الصحيحة، ثم السرعة.

## الميزات عبر الإنترنت (Firebase)

تعتمد على Firebase: تسجيل دخول مجهول (بلا بريد ولا كلمة مرور) و Cloud Firestore. الخطة المجانية تكفي لبداية المشروع.
بدون إعداد Firebase يعمل التطبيق كالمعتاد، وتظهر هذه الميزات كأنها غير مفعّلة.

**الإعداد (مرة واحدة):**
1. أنشئ مشروعاً في [Firebase Console](https://console.firebase.google.com).
2. أضف تطبيق Android باسم الحزمة `com.xmentarik.quiz`، ونزّل ملف `google-services.json` وضعه في مجلد `app/`.
3. في **Authentication ← Sign-in method** فعّل **Anonymous**.
4. في **Firestore Database** أنشئ قاعدة بيانات.
5. انشر قواعد الحماية:
   ```bash
   npm install -g firebase-tools
   firebase login
   firebase use --add          # اختر مشروعك
   firebase deploy --only firestore:rules
   ```

**بنية البيانات:**
| المسار | المحتوى |
|---|---|
| `leaderboard/{uid}` | الاسم، أفضل رصيد، عدد المباريات، مرات الفوز بالمليون |
| `challenges/{code}` | صاحب التحدي، اللغة، والأسئلة الخمسة عشر (JSON) |
| `challenges/{code}/results/{uid}` | نتيجة كل لاعب: الرصيد، الإجابات الصحيحة، المدة |
| `reports/{id}` | بلاغات الأسئلة (للقراءة من Console فقط) |

**الحماية (`firestore.rules`):** لا يكتب كل لاعب إلا بياناته، ولا يُقبل إلا رصيد من سلّم الجوائز. أفضل رصيد لا ينقص، وللاعب محاولة واحدة في كل تحدٍّ، ولا يمكن تعديل التحدي بعد إنشائه.
هذه القواعد مختبرة على محاكي Firestore الحقيقي (14 اختباراً):
```bash
cd firestore-tests && npm install && npm test
```

> ⚠️ **حدود الحماية:** النتائج يرسلها الهاتف، فالقواعد تمنع القيم المستحيلة لكنها لا تثبت أن اللاعب أجاب فعلاً. الغشّاش المحترف يستطيع إرسال 1,000,000. إذا كبر التطبيق، انقل التحقق إلى الخادم (Cloud Functions تتحقق من كل إجابة).

## بنك الأسئلة

ولّدنا الأسئلة مرة واحدة بالسكربت `tools/questions/generate_bank.py` (أداة للمطوّر فقط، خارج التطبيق). التطبيق نفسه لا يتصل بأي ذكاء اصطناعي: كل الأسئلة مدمجة فيه. المفتاح المجاني لـ Gemini محدود بحوالي **20 طلباً في اليوم لكل نموذج**، لذلك يكمل السكربت من حيث توقف.

| المرحلة | ما يحدث |
|---|---|
| `generate` | 10 مواضيع × 3 مستويات × 40 سؤالاً، كل سؤال بالعربية والفرنسية والإنجليزية في الوقت نفسه |
| `verify` | نموذج **آخر** يجيب عن كل سؤال دون أن يعرف الجواب |
| `build` | حذف الأسئلة الخاطئة أو الغامضة أو التي تتغير مع الزمن (الأرقام القياسية، «العاصمة الحالية»…) أو المترجمة خطأً أو المكررة |

النتيجة: 1,202 سؤالاً مرشحاً، قُبل منها 1,033. حُذف 112 لأنها مكررة، و18 لأنها قد تتغير مع الزمن، و18 لأن صعوبتها غير مناسبة، و11 لخطأ في الترجمة، و10 لأسباب أخرى.

لإضافة أسئلة جديدة لاحقاً، أعد تشغيل المراحل الثلاث. السكربت يكمل من حيث توقف إذا نفد الرصيد اليومي:
```bash
python3 tools/questions/generate_bank.py generate
python3 tools/questions/generate_bank.py verify
python3 tools/questions/generate_bank.py build
```

## Firebase في هذا المشروع

- المشروع: `road-to-a-million-b4c41` (ملف `.firebaserc`)، مستقل عن مشاريعك الأخرى. قاعدة Firestore في `europe-west1`.
- **`app/google-services.json` غير موجود في GitHub عمداً،** لأن المستودع عام والملف يحتوي على مفاتيح API. انسخه يدوياً إلى مجلد `app/` على جهازك.
- في Firebase Console: فعّل **Anonymous** في Authentication، وأنشئ قاعدة **Firestore**، ثم انشر القواعد: `firebase deploy --only firestore:rules`.
- إذا كان مفتاح API مقيّداً في Google Cloud Console، أضف إليه الحزمة `com.xmentarik.quiz` مع بصمة SHA-1 الخاصة بتوقيع التطبيق.

## بلاغات اللاعبين

- **مع Firebase:** تصل البلاغات إلى مجموعة `reports` في Firestore. تراها من **Firebase Console ← Firestore** فقط، ولا يستطيع أحد قراءتها من التطبيق. كل بلاغ يحتوي على السؤال كما ظهر للاعب، والإجابة الصحيحة، واختيار اللاعب، والسبب، والتعليق.
- **بدون Firebase:** أضف `REPORT_EMAIL=بريدك@example.com` في `local.properties`، فيفتح الزر تطبيق البريد برسالة جاهزة. إذا لم يوجد Firebase ولا بريد، يختفي الزر.
- **لحذف سؤال خاطئ من اللغات الثلاث** (رقم السؤال مذكور في البلاغ):
  ```bash
  python3 tools/questions/remove_questions.py g3-3-0-01
  ```

## الصوت والموسيقى

| الحالة | ما يُسمع |
|---|---|
| القائمة الرئيسية | لحن أوركسترالي هادئ (`music_menu`) |
| الأسئلة 1–5 | توتر خفيف: نبض منخفض وتكتكة ساعة (`music_calm`) |
| الأسئلة 6–10 | توتر أعلى: نبضات قلب وإيقاع متسارع (`music_tense`) |
| الأسئلة 11–15 | تشويق شديد: وتريات مرتعشة ونبض قلب (`music_intense`) |
| «إجابة نهائية؟» | تتوقف الموسيقى وتُسمع ضربة تشويق صاعدة لمدة 1.5 ثانية |
| النتيجة | إجابة صحيحة، أو نقطة أمان (فانفار)، أو خطأ، أو انتهاء الوقت، أو انسحاب، أو الفوز بالمليون |
| أخرى | اختيار إجابة، وسيلة مساعدة، السؤال التالي، بداية اللعبة، وتكتكة في آخر 10 ثوانٍ |

- يمكن إيقاف المؤثرات أو الموسيقى من الشاشة الرئيسية، ويُحفظ الاختيار.
- تتوقف الموسيقى تلقائياً عند الخروج من التطبيق وتعود عند الرجوع إليه.
- كل الأصوات **مولَّدة برمجياً** بالسكربت `tools/audio/generate_sounds.py`، فلا توجد مشكلة حقوق. لإعادة توليدها بعد تعديل السكربت:
  ```bash
  pip install numpy   # ويلزم ffmpeg
  python3 tools/audio/generate_sounds.py app/src/main/res/raw
  ```
- لاستبدال أي صوت بتسجيل احترافي، ضع ملف OGG بالاسم نفسه في `app/src/main/res/raw/`. تأكد من أن الترخيص يسمح بالاستخدام التجاري (مثل CC0 أو Pixabay).

## التشغيل في Android Studio

1. افتح المجلد في Android Studio (نسخة Ladybug أو أحدث) واترك Gradle يحمّل المكتبات.
2. انسخ ملف `google-services.json` (من Firebase) إلى مجلد `app/`.
3. شغّل التطبيق على محاكٍ أو هاتف (Android 8.0 / API 26 فما فوق).

> إذا اقترح Android Studio ترقية Android Gradle Plugin، فاقبلها عبر *AGP Upgrade Assistant*.

الاختبارات: `./gradlew test`
